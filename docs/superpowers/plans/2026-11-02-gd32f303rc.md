# GD32F303RC Implementation Plan

Goal: Build a PB15 active-high blink and USART1 PA2/PA3 console demo for GD32F303RCT6.

Architecture: Independent out-of-tree board and application, using existing GD32F303 SoC drivers. 256 KiB Flash, 48 KiB SRAM, 8 MHz HXTAL. DAP-Link uses SWD. No hardware programming during implementation.

Spec: Hardware parameters confirmed in this chat. Prefer an independent board over modifying the vendor START board, to preserve its original wiring.

- [x] Add board DTS, Kconfig, metadata, pinctrl and runner configuration.
- [x] Add blink/console application and CMD build entry point.
- [x] Compile using SDK 1.0.1 and inspect generated DTS, configuration and ELF.
- [x] Document wiring and outstanding hardware validation.

Validation: full 150-step build passed. FLASH 15780 bytes / 256 KiB, RAM 4352 bytes / 48 KiB. OpenOCD noinit parsing passed without accessing hardware. Board execution and flash driver compatibility remain unverified on hardware.

Ruling: use SDK-provided stm32f1x compatible flash configuration with Cortex-M4 SWD ID instead of a nonexistent gd32f3x0.cfg. Hardware probe and erase/program validation remain required before treating flashing as verified.
